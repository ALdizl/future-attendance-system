نظام الحضور والغياب - أكاديمية المستقبل

تشغيل على جهازك (للتجربة):
1) pip install -r requirements.txt
2) python init_db.py          (بينشئ قاعدة بيانات فيها حسابات تجريبية)
3) python app.py   ثم افتح http://127.0.0.1:5000

النشر أونلاين: اقرا ملف DEPLOY.txt  (بيستخدم setup_production.py بدل init_db.py، من غير حسابات تجريبية)
